#### 🎓 [AI Teacher — LLM-Powered Learning Platform](https://github.com/Abhishek220801/ai-teacher-ui)

An AI-driven learning platform that turns a user-defined technology topic into a structured, interactive course.

**User provides:**

- Language — English / Hinglish

- 💻 Provides syntax-highlighted code blocks
- 🧭 Supports previous/next chapter navigation
- 🔎 Provides course search and management

**Stack:** TypeScript • Node.js • Express.js • React • MongoDB • LLM APIs • Prompt Engineering • Structured Outputs
